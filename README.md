An ultra-modern, high-octane web portal designed for Eastern India's biggest management & cultural festival — **Xpressions 2027** (XIM Bhubaneswar). 

Crafted with brutalist/editorial typography, high-contrast neon festival red (`#F12B25`) and electric blue (`#1554D1`), volumetric stage lighting, and an exact replica of IIT Bombay's **Mood Indigo (`moodi.org`)** layout DNA.

---

## ⚡ Highlights & Key Features

- 🎸 **Concert Light Beams & Particle Engine**: Dynamic 2D HTML5 Canvas particle system rendering falling light sparkles with interactive cursor reactions.
- 🔊 **Seamless Background Audio Looper**: Zero-delay looping audio player with animated equalizer bars, streaming Karan Aujla's *WAVY*.
- 🎯 **High-Tech Fluid Cursor**: 60fps Lerp-interpolated dual-ring cyberpunk targeting pointer with hover expansion and click ripple.
- 👾 **3D Retro Pixel Typography**: Custom extruded arcade typography inspired by retro 16-bit concert stage marquee graphics.
- 📅 **Dynamic Multi-Tier Schedule Matrix**: Filter events across *Concerts*, *Competitions*, *Pro Shows*, and *Workshops* with day-by-day diversification (*Day 1 / Day 2 / Day 3*).
- 💎 **Interactive Official Sponsor Wall**: High-res widescreen sponsor showcase with 50+ national brands and an interactive proposal modal.
- 👑 **Neon Festival Loading Sequence**: Mood Indigo-style cybernetic bootloader with live telemetry counter (`0% -> 100%`).
- ⚡ **Route-Aware Browser Tab Easter Egg**: Dynamic tab title updates based on route, and reminds users to return when they switch away!

## 🚀 Quick Start

Run the project locally with zero setup:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/xpressions-2027.git

# 2. Enter the directory
cd xpressions-2027

# 3. Quick Run on Windows (One-Click)
run.bat

# Or run via terminal:
npm install
npm run dev
```

Visit [`http://localhost:3000`](http://localhost:3000) to enter the festival experience.

---

## 🛠️ Tech Stack

- **Framework**: React 18 (SPA with HashRouter)
- **Bundler**: Vite 5
- **Styling**: Tailwind CSS + Custom Keyframe Engine (`animations.css`)
- **Icons**: Lucide React
- **Animations**: Framer Motion + Canvas 2D
- **Audio**: Web Audio API & HTML5 Audio Loop Engine
